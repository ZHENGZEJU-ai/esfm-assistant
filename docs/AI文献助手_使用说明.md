## 二、怎么用（两种方式）

### 方式 1：直接问我（推荐）

在 Cowork 里直接问，比如：

> “静电薄膜电机的推力密度目前做到多少了？给我原文出处”
> “electret 型和感应型静电电机各有什么优缺点？”
> “有哪些工作在研究推力波动(force ripple)？”
> “帮我写一段 related work，讲多层薄膜静电驱动器的发展”

我会**自动做三件事**：
1. 把你的问题扩展成一组同义术语（中→英、口语→术语）——这就是"语义层"，由我来补；
2. 调用 `ask.py` 在你的库里检索；
3. **带着 DOI 和页码**回答你，每个结论都能溯源到原文。

### 方式 2：自己命令行查

```bash
cd F:\DataBase

python ask.py "thrust force density"           # 段落检索(带出处)
python ask.py "electret motor" -n 15           # 返回15条
python ask.py "dual excitation" --tier 1       # 只在①核心里搜
python ask.py --paper "Egawa"                  # 按作者/标题找论文
python ask.py --stats                          # 库统计
```

**检索语法**（FTS5）：
- 空格 = AND：`electrostatic film motor`
- `OR` = 或：`thrust OR force`
- `"..."` = 精确词组：`"dual excitation"`
- `*` = 前缀：`actuat*` 匹配 actuator/actuation
- `NOT` = 排除

## 三、能满足你的四个需求

**① 问答与溯源** — 直接问，我带 DOI + 页码回答，可核对原文。

**② 性能参数抽取** — 让我"把①核心里所有报告过推力密度的工作整理成对比表"，我检索后逐篇读原文段落，汇成 Excel（推力/推力密度、驱动电压、速度、电极节距、结构、材料）。

**③ 写作辅助** — 让我"写一段关于 XX 的 related work"，我基于库里原文写，并给出可直接引用的文献列表。

**④ 跟踪新文献** — 让我定期（如每周）用 OpenAlex 检索该领域新论文，增量入库并更新索引。可以设成定时任务。

---

## 四、维护

**新增论文后重建索引**：把新 PDF 放进 `PDFs\00_film_motor_focus\`，然后让我重跑一遍抽取+建索引即可（几分钟）。

**关于语义检索**：当前用「关键词索引 + 我做查询扩展」，零依赖、离线、免费，效果已足够。如果以后论文量涨到上千篇、需要更强的语义匹配，可以再加一层本地 embedding 向量检索。

---

## 五、局限

- **只有 195 篇有全文**。目录里另外 363 篇是付费墙/未下载的（IOP 的 JMM、SPIE、Springer 等），检索不到正文，但 Excel 目录里有 DOI 可查。
- 全文抽自 PDF，**老论文（扫描版）可能有 OCR 噪声**，公式和表格会变形。
- 引用页码以 PDF 页序为准。
