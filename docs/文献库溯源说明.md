## 如何使用目录（Excel）

`电静电驱动器_论文库目录.xlsx` 有两个工作表：

- **文献目录**：每行一篇论文，含 方向 / 标题 / 作者 / 年份 / 期刊 / 被引次数 / DOI / 开放获取状态 / 本地PDF / 本地文件路径（超链接）/ PDF链接 / DOI链接 / 摘要。表头已冻结并开启筛选，可按方向、年份、被引次数等排序筛选。
- **统计**：整体数量统计。

「本地PDF」列标「已下载」的论文，可点击「本地文件路径」直接打开 PDF。
